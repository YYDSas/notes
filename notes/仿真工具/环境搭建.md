## 二、slang / slang-server（免费 LSP 方案）

| 工具 | 说明 |
| --- | --- |
| **slang** | Mike Popoloski（HRT）写的 SystemVerilog 前端库（MIT），含 CLI 可编译+lint 整个 SV 工程；CHIPS Alliance sv-tests 唯一全通过的开放前端。官网 sv-lang.com，有 Windows 预编译二进制 |
| **slang-server** | HRT「Surge」项目的 SV **LSP 语言服务器**（MIT，2026 年初开源）；客户端是 VS Code 扩展 `vscode-slang`（publisher **Hudson-River-Trading**，会自动下载二进制，无需 license）与 Neovim 插件 |

**能力**：实时 lint、跳转定义/引用/补全、inlay hints、按 `.f` 文件列表与 top elaborate 后浏览层次树、与波形查看器互跳。

**边界（要讲清）**：

- 它是 **SV 语言层面**工具；UVM 代码靠"UVM 也是纯 SV 类库"才能跳转
- **没有** DVT 那种 UVM 方法论视图（Sequence/Component 层次、工厂关系图）
- 用前**必须配好 `.f` / `+define+` / `+incdir+`**，否则 UVM 宏解析不了

> ⚠️ 本机因网络（`curl` 走代理访问 github 502）**未能下载 slang CLI**，
> 故实际 lint 效果未在本机验证。网络可通时可补下 `MikePopoloski/slang` 的 Windows zip。

## 三、gvim（轻量、贴合截图里的效果）

**已落地**：Vim 9.2 Huge（`C:\Program Files\Vim\vim92\gvim.exe`），vim-plug 已装。

**关键坑（务必记住）**：

> **Vim 的 `$HOME` 是 `C:\Users\86150\AppData\Roaming\SPB_Data`**（SPB_Data 环境变量导致），
> **用户级 vimfiles 在 `SPB_Data\vimfiles\`，不是 `C:\Users\86150\vimfiles`。**

| 项 | 内容 |
| --- | --- |
| 主配置 | `SPB_Data\vimfiles\gvimrc_svuvm.vim`（插件 rtp 注入 + 外观 + F2 文件树/F8 大纲/标签页键位） |
| 启用 | 需在 `C:\Program Files\Vim\_vimrc` 末尾手动加 `source` 行（该文件需管理员权限） |
| 插件（9 个） | verilog_systemverilog.vim、systemverilog.vim(sqlmap3)、nerdtree、tagbar、vim-airline(+themes)、auto-pairs、vim-commentary、gruvbox |
| 安装方式 | 通过 `ghfast.top` 镜像 clone 到 `SPB_Data\vimfiles\plugged\` |
| 实测 | `filetype=systemverilog`、`shiftwidth=2`、`foldmethod=syntax`、`uvmMacro`/`svSysTask` 高亮均生效 |

**两处注意**：① 原 `_vimrc` 把 `*.sv` 抢成 `verilog`，已统一为 `systemverilog`；
② 原 `F2→:Lexplore` 与新 `F2→NERDTree` 冲突，建议删原映射。
③ 想用 F8 大纲需装 **Universal Ctags**（Exuberant Ctags 不支持 SV）。

**Vim 无头调试技巧**：`-u NONE -c "..."` 下 `echo` 无输出，改用
`-c "execute 'redir! > file'"` 或写独立脚本用 `writefile()`。

## 四、DVT Eclipse（商业 IDE）

路科实验里出现的那个 IDE：**DVT Eclipse**（AMIQ EDA，2022 年被 Synopsys 收购），
基于 Eclipse 的 SV/UVM 专用 IDE，**本身不是仿真器**。

- 识别特征：独立 `UVM` 菜单、Projects 里的 `DVT-Examples` / `[dvt]` nature、`Probe`/`Checks`/`Layers`/`UVM Se` 视图
- 有 Windows 版（26.x）；三种用法：官方 Windows 包 + `DVT_HOME`、给已有 Eclipse 装 update site、**DVT IDE for VS Code**（扩展 id `amiq.dvt`）
- 授权：商业（约 975 USD/年起），另有 **Evaluation 试用** 与 **Academic 学术授权**
- 装 DVT 需用 **Command Prompt 而非 PowerShell** 运行 `dvt_kit_installer.bat`
- 价值：**UVM 方法论视图**（Sequence/Component 层次、工厂关系图）——这是免费方案给不了的

## 五、C 工具链（DPI 必需）

- **w64devkit v1.23.0**（MinGW-w64，GCC 14.1.0 + GNU Make 4.4.1）解压在 **`E:\Mingwn`**
- 用法：`export PATH="/e/Mingwn/bin:$PATH"`（**未写入系统 PATH**）
- 配置为 `--enable-static --disable-shared`：做 DPI 动态库时无需附带 `libstdc++-6.dll` / `libgcc_s_seh-1.dll`，**DLL 自包含**
- 为什么需要：Questa 的 DPI 必须要 C 编译器，否则 `vsim-7019`
- 解压坑：Git Bash 的 `unzip` 会报 `checkdir error`；改用 `/c/Windows/System32/tar.exe -xf`（bsdtar）正常

详细 DPI 流程见 [[仿真工具 · Questa 避坑手册]]。
