## 一、怎么用这套材料

### 场景 A：马上要动手写验证

1. 先默念一遍 [[验证工程 · 骨架速记]] 的**八股图 + 三级配置链 + 7 步顺序**
2. 按骨架速记第五节的顺序依次打开文件填
3. 卡在某一块 → 翻对应的那篇

### 场景 B：每天复习（建议 10 分钟）

只看 [[验证工程 · 骨架速记]]，重点是：
- **第八股结构图**（能默画出来就过关）
- **三级配置链的 set/get 对应关系**
- **第 6 节那 7 个静默失败**（这是最容易翻车的地方）

配合自测页的"今日复习"效果更好。

## 三、这套材料从哪来

**不是凭空写的模板，是实测出来的。**

来源：用一个 AXI4-Lite 从设备 VIP（1600 行，6 个 test）
把 [[UVM · 知识地图]] 里的机制逐条落到工程上，

`0 mismatch 0 error`，功能覆盖率 88.83%。

所以这里每条"★★"标记的规则背后都有一次真实的调试，

## 四、核心口诀（背这四句）

```
1. 一个接口 = 一个 agent
2. 一个 item  = 一次完整事务
3. 一个 test  = 一个激励场景 + 一组配置
4. 先写冒烟测试，再上 UVM
```

第 4 条是本次实践里最值钱的经验 —— 20 行纯 SV 换来 3 个 RTL bug 的秒级定位。
