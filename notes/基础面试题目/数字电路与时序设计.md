# 面试题 · 数字电路与时序设计

> 汇总自《面试总结》设计部分第 1~22 题。这是 IC 验证岗面试里**最容易答不上来**的一块——因为平时只当"验设计的"，但面试官就是要看你懂不懂底层。

## 1. 什么是竞争和冒险？

- **竞争**：在组合电路中，输入变量经过**不同途径**传输后，到达电路中某汇合点的时间**有先有后**的现象。
- **冒险**：由于竞争而使电路输出发生**瞬时错误**（毛刺）的现象。

## 2. 怎么判断竞争和冒险？怎么消除？

**判断方法**

- **代数法**：如果布尔式中出现**相反的信号**（如 `A·A'`），则可能产生竞争和冒险。
- **卡诺图法**：有**两个相切的分卡诺图**，且相切处**没有被其他卡诺圈包围**，就可能出现竞争冒险。

**解决方案**

1. 加**滤波电容**
2. 引入**选通信号**
3. 增加**冗余项**
4. **信号延时法**

## 3. 触发器和锁存器有什么区别？各自优缺点？

**锁存器**：**电平触发**。使能信号有效时相当于通路，无效时保持输出状态。
**触发器**：**时钟触发**。只有在时钟触发时才采样当前输入、产生输出。

| | 锁存器 | 触发器 |
| --- | --- | --- |
| 触发方式 | 电平 | 时钟 |
| 缺点 | 对输入电平敏感，受布线延迟影响大，输出可能产生毛刺 | — |
| 优点 | 面积**小**、速度**快**；用门电路搭建时消耗门资源少，功耗更低 | — |

## 4. 阻塞赋值和非阻塞赋值的区别？

| | 阻塞 `=` | 非阻塞 `<=` |
| --- | --- | --- |
| 执行 | **必须**阻塞赋值完成后才执行下一条 | 赋值**开始时**算右边，**本仿真周期结束时**才更新左边 |
| 生效 | 赋值一旦完成，左边**立即**变化 | **不是立即生效**，允许块中其他语句同时执行 |
| 顺序影响 | 有 | 同一块中书写顺序**不影响**结果 |
| 硬件 | 没有对应电路 | **有对应电路** |

记忆：**阻塞 = 串行 + 立即生效**；**非阻塞 = 并行 + 同时执行**。

> **规范：组合逻辑用阻塞赋值，时序逻辑用非阻塞赋值。**

## 5. 同步电路和异步电路的区别？

**同步电路**：所有触发器的时钟输入都接**同一个时钟脉冲**，所有触发器的状态都与所加时钟同步。
**异步电路**：没有统一时钟，有些触发器的时钟与时钟脉冲相连，有些没有。

| | 异步电路 | 同步时序电路 |
| --- | --- | --- |
| 核心逻辑 | 用**组合电路**实现 | 用**时钟触发器**实现 |
| 主要信号 | — | 由时钟触发器产生 |
| 毛刺 | **容易产生** | 能很好避免 |
| 器件移植 | 不利 | 利 |
| 静态时序分析（STA） | 不利 | 利 |

## 6. 什么是亚稳态？怎么产生？怎么消除？

**亚稳态**：如果数据在时钟上升沿的**建立时间和保持时间内**发生跳变，就会产生亚稳态输出——输出值在短时间内处于**不确定态**，可能是 1、可能是 0、也可能什么都不是，处于中间态。

**产生原因**：违反了寄存器的建立时间和保持时间。

**消除方法**

1. 跨时钟域信号传输使用 **FIFO** 进行数据缓冲
2. 复位电路采用**异步复位、同步释放**
3. 用**反应更快的 FF**
4. 用**边沿变化快速的时钟信号**
5. **降低系统时钟频率**

## 7. 建立时间、保持时间、恢复时间、移除时间？

| 名词 | 定义 |
| --- | --- |
| **建立时间（setup）** | 在时钟沿到来**之前**，触发器输入端的数据必须保持不变的**最小时间** |
| **保持时间（hold）** | 在时钟沿到来**之后**，触发器输入端的数据必须保持不变的**最小时间** |
| **恢复时间（recovery）** | 在**撤销复位**时，非复位状态必须在时钟有效沿到来**之前**一段时间内达到 |
| **移除时间（removal）** | 在**撤销复位**时，在时钟沿到来**之后**复位信号还要保持的时间 |

后两个只对**异步复位**有意义：异步复位释放时若刚好落在时钟沿附近，寄存器输出会亚稳态，所以要规定"必须提前多久放开"和"放开后还要保持多久"。

## 8. 什么是时间抖动（jitter）和时钟偏移（skew）？

- **时间抖动**：在某一个给定点上时钟周期发生短暂性变化，使时钟周期在不同周期上可能**加长或缩短**。发生在**时钟发生器内部**，和晶振抖动以及外部电路有关。
  - `抖动 = T2 - T1`（**频率上的不确定**）
- **时钟偏移（skew）**：同一个时钟信号到达**相邻两个时序单元**的时间不一致，主要由**布线长度和负载**不同引起。
  - `偏移 = Tc2d - Tc2s`（**相位上的不确定**）

## 9. 同步复位和异步复位？

**同步复位**：复位信号只有在时钟上升沿到来时才有效 → `always@(posedge CLK)`

优点：① 利于仿真器仿真 ② 可滤除高于时钟频率的毛刺 ③ 有利于时序分析

缺点：① 有效时长必须**大于时钟周期**才能被识别 ② 目标器件库内 DFF 通常只有**异步复位端口**，用同步复位会在数据输入端插入组合逻辑，耗费较多逻辑资源

**异步复位**：无论时钟沿是否到来，只要复位有效就复位 → `always@(posedge CLK or negedge Rst_n)`

优点：① 设计简单 ② 器件库有异步复位端口，省资源 ③ 识别方便，可方便使用 FPGA 全局复位端口 GSR

缺点：① 容易受毛刺干扰 ② **若复位释放刚好在时钟有效沿附近，寄存器输出容易出现亚稳态**

> **推荐方案：异步复位、同步释放**。复位**到来**时不与时钟同步，**释放**时与时钟同步，从而避免亚稳态。

## 10. 格雷码有什么好处？

**相邻之间只变 1 bit**，因此计数过程中最多出现一位错误，大大避免了亚稳态的发生。

> ★ **注意使用前提**：3 bit 数据必须在 0~7 范围内才能用格雷码。如果范围是 0~6 就**不能**用——因为从 6 变到 0 格雷码变化了**不止一位**。

## 11. 跨时钟域：多 bit 信号能打两拍吗？

**不能。** 各 bit 之间路径延迟不一样，源时钟域给的是 `2'b11`，目的时钟域采样到可能是 `2'b10`。所以多 bit 数据跨时钟**不能采用打两拍的方法**。

### 单 bit 跨时钟域

- **慢到快**：打两拍。采集到的信号处于亚稳态（既不是 1 也不是 0，暂时中间态），需要打两拍让信号稳定下来，恢复成原信号。
- **快到慢**：在快时钟域上信号最宽，同步到慢时钟域再打两拍。

**两级触发器防亚稳态传播的原理**：假设第一级触发器的输入不再满足建立保持时间，它在第一个脉冲沿到来后输出即为亚稳态。在**下一个脉冲沿到来之前**，亚稳态数据经过一段恢复时间后**稳定下来**，且稳定后的数据满足第二级触发器的建立时间。如果都满足，第二级触发器就不会出现亚稳态。

### 多 bit 跨时钟域的做法

| 方法 | 说明 |
| --- | --- |
| **格雷码** | 主要避免亚稳态；注意取值范围必须是 2^n（如 3 bit 要 0~7） |
| **异步 FIFO** | 最常用 |
| **握手（DMX）** | 相当于触发器的使能信号。判断源时钟域的单 bit 信号是否在目的时钟域**成功同步**；如果是，那么这个时间长度下多 bit 信号也可以同步过来且不违背建立时间 |
| **握手协议** | 显式握手，最稳但开销大 |

## 12. 同步 FIFO 和异步 FIFO 的区别？

**FIFO**：先进先出数据缓存器。与普通存储器的区别是**没有外部读写地址线**，使用简单，缺点是只能**顺序读写，不能随机读写**。

- **同步 FIFO**：读写是**同一个时钟**，一般用作交互数据的缓冲。
- **异步 FIFO**：读写是**不同的时钟**。两个主要作用：① 实现数据在**不同时钟域**间传递 ② 实现**不同数据位宽的变换**（输入 16bit、输出 8bit）。

### 空满判断

**同步 FIFO**（计数**二进制扩展一位**）：

- 空：读写地址**完全相同**
- 满：读写地址**最高位不同，其余位均相同**

**异步 FIFO**（计数用**格雷码**）：

- 空：读写地址**完全相同**
- 满：读写地址**高 2 位不同，其余位均相同**

> 用格雷码是因为相邻计数只变 1 bit，跨域同步时不会因多位同时翻转产生中间态。

## 13. 什么是门控时钟？它怎么降功耗？

**门控时钟（gating clock）**：在时钟路径上增加**逻辑门**对时钟进行控制，使部分模块在不需要工作时**停止时钟树的翻转**，而不影响原本的逻辑状态。此时该模块相当于处于**静态功耗**，从而降低系统功耗。

## 14. 低功耗设计方法？

- **动态功耗** = 开关功耗 + 短路功耗
- **静态功耗**由**漏电流**引起
- **浪涌**（surge）指状态切换瞬间的电流尖峰

**降低静态功耗**：电源门控、多阈值电压（MVT）

**降低动态功耗**：多电压供电、门控时钟、动态电压频率调节（DVFS）、并行结构与流水线技术

**影响动态功耗的因素**：电压、温度、工作频率

### RTL 级降功耗

1. **资源共享**：多处使用同一个逻辑运算就直接复用，不用每处都重算。
2. **状态编码**：用**格雷码或独热码**编码。多 bit 信号频繁变化时会产生很多翻转功耗。
3. **门控时钟**：时钟翻转会产生很大的翻转功耗，不需要工作时停止时钟树翻转，使模块进入静态功耗。

## 15. 什么是线与？

线与逻辑是两个输出信号相连实现与的功能。硬件上要用 **OC 门**（漏极或集电极开路）实现。为了防止某支电流过大烧坏 OC 门，应在 OC 门输出端接一个**上拉电阻**（线或是**下拉电阻**）。

## 16. 组合逻辑电路和时序逻辑电路的区别？

- **组合逻辑**：任意时刻的输出**仅取决于该时刻的输入**，与电路原来的状态无关。常见：加法器、比较器、译码器、编码器。
- **时序逻辑**：任意时刻的输出**不仅取决于当时的输入，还取决于电路原来的状态**。常见：触发器、移位寄存器、计数器、序列信号发生器。

## 17. 怎么用 MOS 管搭二输入与非门、或非门？

- **与非门**：上面两个 PMOS **并联**，下面两个 NMOS **串联**。
- **或非门**：上面两个 PMOS **串联**，下面两个 NMOS **并联**。

口诀：**与非 = 上并下串；或非 = 上串下并**。

## 18. 状态机一段式、两段式、三段式的区别？

| | always 块数 | 特点 |
| --- | --- | --- |
| **一段式** | 1 个 | 组合逻辑和时序逻辑混在一起。增加代码复杂度，不利于维护和修改，也不利于后期约束 |
| **两段式** | 2 个 | 组合逻辑与时序逻辑分开：1 个同步时序描述状态转移，1 个组合逻辑判断转移条件、描述转移规律及输出 |
| **三段式** | 3 个 | 关键区别是**在组合逻辑后增加一级寄存器**实现逻辑输出。同样清晰，但**能有效滤除两段式组合逻辑输出可能产生的毛刺** |

两段式和三段式代码清晰，降低编写维护复杂度，完整显示状态机结构。

## 19. `reg` 和 `wire` 的区别？

1. `wire` 相当于**物理连线**，两端输入有变化输出马上反映；`reg` 相当于**存储单元**，一定要触发输出才反映输入状态。
2. `wire` 用在**连续赋值**语句中（`assign`）；`reg` 用在**过程语句**中（`initial`、`always`）。

## 20. `initial` 和 `always` 的区别？

- **`initial`**：只能用于测试，**只执行一次**，**不可综合**。
- **`always`**：用来描述硬件时序和组合电路，**可综合**。

## 21. 什么是 critical path？怎么处理？

**关键路径**通常指**同步逻辑电路中，组合逻辑时延最大的路径**，是对设计性能起决定性影响的时序路径。

处理：拆长逻辑（加流水级）、优化组合逻辑层级、多用专用单元。

## 22. 什么是静态时序分析（STA）和动态时序分析？

**STA（静态时序分析）**：采用**穷尽分析**方法提取整个电路存在的**所有时序路径**，计算信号在这些路径上的传播延时，检查信号是否满足建立和保持时间要求。通过对最大路径延时和最小路径延时的分析，找出**违例时序**。

不需要输入激励数据，运行速度快、占用内存少，还能**反过来优化设计**。工具：Synopsys PrimeTime。

**动态时序分析**就是通常的**仿真**。因为不可能产生完备的测试向量覆盖网表中每一条路径，所以**无法暴露某些路径上可能存在的时序问题**。

> 这就是"前仿查不出建立保持时间/亚稳态"的根本原因。
