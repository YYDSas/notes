> 本页是 SV错题本 分类的**总目录**。
> 核心用法：**三种查法** —— ① 报错了往上翻「按报错查」；② 想不通翻「按想不通查」；
> ③ **没报错但结果不对**，翻「按静默失败查」。写代码前扫一遍「自查清单」。

## 一、三类错误的区别

| 类型 | 特点 | 编译器 | 笔记 |
| --- | --- | --- | --- |
| **代码书写类** | 手滑/疏忽，重复率高，修起来快 | ✅ 能抓出来 | [[错题本 · 代码书写类]] |
| **结构理解类** | 概念理解偏了，看着对其实错 | ❌ 抓不出来 | [[错题本 · 结构理解类]] |
| **静默失败类** | 编译过、不报错，但结果错 / 你以为验证过了 | ❌ 且**不提醒你** | [[错题本 · 静默失败类]] |

> 一句话：**书写类让你编译不过；理解类让你编译通过但结果是错的；静默类让你连"结果是错的"都不知道。**
> 越往下越危险。

## 二、按报错查（代码书写类）

| 编译器报什么 | 你漏了什么 |
| --- | --- |
| `near "xxx": syntax error, expecting ';'` | **函数/任务头漏分号**（最高频） |
| **一连串报错都指向同一个类/包之后** | `endclass` / `endgroup` / `endmodule` **漏了**（最致命） |
| `Illegal declaration after the statement` | 声明写在了语句之后 |
| `Undefined variable: 'xxx'` | 拼写错误，或引用了**别的作用域**的名字 |
| `Too few arguments`（宏 / 函数） | `` `uvm_info `` 少参数（要 **3** 个）、`get` 少参数 |
| `Illegal use of a type name as an expression` | 把**类名**当变量传给了函数 |
| `syntax error, unexpected begin` | `foreach` 拼错 |
| `Illegal access to local/protected member` | 访问了不该访问的成员 |
| `Arguments to $cast must be singular` | `$cast` 的目标不是单值（写成了数组等） |
| `vsim-3971 $cast to type 'X' from 'Y' failed` | `$cast` 目标侧的值不是合法枚举成员（**先确认方向没写反**） |
| `vsim-12051 Illegal assignment in cast to class` | 类句柄用了静态转换 `T'(...)`，必须换 `$cast` |
| 编译通过但返回值是 0 | 有返回值的函数**漏写 `return`**（无警告！） |
| 运行时段错误 `signo [11]` | 空句柄上访问成员 |
| 找不到顶层 / `Error loading design` | **模块名 ≠ 命令行里的顶层名**（文件名/模块名/命令三处要一致） |
| 覆盖率 `.ucdb` 没生成 | `coverage save -onexit` 写在了 `run` 之后（被 `$finish` 吃掉） |

详见 [[错题本 · 代码书写类]]。

## 三、按"想不通"查（结构理解类）

| 我以为是… | 其实是… |
| --- | --- |
| `super` 是个句柄 | `super` 是「**父类版本的方法**」，跟句柄无关 |
| `$cast` 会创建对象/转数据 | 只**加一个句柄 + 查类型**，不建对象不拷数据 |
| 枚举和整型可以随便互转 | `enum → int` 直接赋值即可；`int → enum` **必须 `$cast`** 查成员 |
| `$cast` 失败后目标会变 null | **保持原值**；源为 null 时反而返回"成功"(`1`) |
| `$cast` 报错信息在说"源类型不对" | 原文是「to type **目标** from **源**」，顺序最容易读反 |
| `t2 = t1` 会产生新对象 | 只是句柄复制，**同一个对象** |
| `fifo[$]` 需要实例化 | 队列**声明即创建**，直接可用 |
| `push_back` 存的是快照 | 存的是**句柄**，改对象后队列里的值跟着变 |
| 子类重写必须写 `virtual` | **关键在基类**，基类写了虚性就继承下来 |
| `virtual` 能让数据成员也多态 | `virtual` **只能修饰方法**，不能修饰数据成员 |
| 循环 4 次 new，内存就是 4 次的和 | `wd = new(i)` 是**句柄重指向**，只有最后一个存活 |
| `uvm_config_db::get` 能取到"对象" | 只取**值或句柄**；第 4 个参数必须是**同类型的变量** |
| 层次路径由**类名**决定 | 由**实例名 + parent** 决定（`create` 的第 1 个参数） |
| 只要"寻址三个参数"一致就万事大吉 | 第 4 个参数是**给什么**，也要检查它到底是多少 |
| `report_phase` 适合再查一次 config | 阶段各有职责：build 造子组件、report 汇报、run 跑激励 |
| covergroup 能看到外面任何变量 | coverpoint 只认**本类作用域**的变量 → 先搬进成员再 `sample()` |

详见 [[错题本 · 结构理解类]]。

## 四、按"没报错但不对"查（静默失败类）

| 我以为… | 其实是… |
| --- | --- |
| `randomize()` 失败会清空变量 | **保持原值**（要先用**哨兵值**才测得出来：`p.length = 777;`） |
| `get` / `$cast` 失败会报错 | **返回 0、静默**，变量/句柄保持原值 |
| 覆盖率 0% 就是没覆盖到 | 也可能是**压根没被采样**（漏 `new()`/`sample()`、组件没被创建） |
| 日志里有那条消息 = 验证过了 | 消息里**没有值**就没有证据力（要 `$sformatf("cfg_val=%0d", cfg_val)`） |
| 打印 0 说明没采到数据 | 也可能**计数器从没被 +1**（漏了 `run_total++`） |
| 报错信息里的变量总是对的 | `i` 没自增 → 永远报"第 0 次"，把你带偏 |
| `randomize()` 返回 1 就成功了 | 动态数组不约束 `size` 时，返回 **1** 但 `size = 0` |

详见 [[错题本 · 静默失败类]]。

## 五、提交前自查清单（速查版）

**代码书写类（14 项）**

- [ ] 每个 `function`/`task` **头部行**末尾有 `;`？
- [ ] 每条赋值、调用末尾有 `;`？
- [ ] 形参名与成员同名时，成员侧写了 `this.`？
- [ ] `foreach` / 类名 / 变量名拼写一致？
- [ ] 声明是否都在语句**之前**？
- [ ] 有返回值的函数，**每条路径**都有 `return`？
- [ ] 动态数组 `[]` 是否 `new[n]` 了？（队列 `[$]` 不用）
- [ ] `$display` 的格式符个数 = 参数个数？
- [ ] **五对括号**都配对了吗（package / class / covergroup / module / begin）？
- [ ] 同类里有没有**同名函数写两遍**（SV 不支持重载）？
- [ ] `类名::type_id::create("实例名", parent)` 三层写全了吗？
- [ ] `` `uvm_info `` 的**三个**参数都在吗？MSG 里带变量值了吗？
- [ ] 文件名 / 模块名 / `vsim` 顶层名**三处一致**吗？
- [ ] 每个源文件开头都有 `` `timescale `` 吗？

**结构理解类（14 项自问）**

- [ ] 这个 `new()` 执行了几次？**当前几个对象存活**？
- [ ] `t2 = t1` 我复制的是对象还是句柄？
- [ ] `super.X()` 我读成"父类版本的方法"了吗？
- [ ] 我对 `$cast` 期待了多余的事吗？
- [ ] 子类构造函数调 `super.new()` 了吗？
- [ ] 这个函数在**改数据**还是**显示数据**？混了吗？
- [ ] 队列 `[$]` 是不是多此一举想给它 `new`？
- [ ] `push_back` 的语义我当"拷值"了吗？
- [ ] `virtual` 我检查的是**基类**还是子类？
- [ ] 题目问的是**当前占用**还是**累计分配**？
- [ ] config_db 的 set/get：拼出的**作用域字符串**一样吗？**值**对吗？
- [ ] 这个层次路径由**类名**还是**实例名**决定？
- [ ] 这个 phase 该干这件事吗？
- [ ] coverpoint 引用的变量，在 covergroup 所在类里**看得到**吗？

**静默失败类（4 问）**

- [ ] 这个函数的**返回值**我判了吗？（`randomize` / `get` / `$cast` 三兄弟）
- [ ] 这条日志里**有值**吗？（证明的是"跑到了"还是"结果对"？）
- [ ] 这个 0 / 全 0%，是"真的是 0"还是"**根本没跑**"？
- [ ] 每个计数器在哪里被 `+1`？报错信息里的变量都有正确来源吗？

## 六、常用验证命令

概念拿不准时，直接跑一遍（本机已装 QuestaSim）：

```bash
vlog -sv 你的文件.sv
vsim -c -do "run -all; quit -f" 顶层模块名
```

> 提示：测试代码的 `$display` 建议用**纯英文**，避免终端中文乱码。
