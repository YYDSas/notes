> 本页是 SV错题本 分类的**总目录**。
> 核心用法：**两种查法** —— ① 报错了往上翻「按报错查」；② 写代码前扫一遍「自查清单」。

## 一、两类错误的区别

| 类型 | 特点 | 编译器 | 笔记 |
| --- | --- | --- | --- |
| **代码书写类** | 手滑/疏忽，重复率高，修起来快 | ✅ 能抓出来 | [[错题本 · 代码书写类]] |
| **结构理解类** | 概念理解偏了，看着对其实错 | ❌ 抓不出来 | [[错题本 · 结构理解类]] |

> 一句话：**书写类让你编译不过，理解类让你编译通过但结果是错的。**
> 后者更危险。

## 二、按报错查（代码书写类）

| 编译器报什么 | 你漏了什么 |
| --- | --- |
| `near "xxx": syntax error, expecting ';'` | **函数/任务头漏分号**（最高频） |
| `Illegal declaration after the statement` | 声明写在了语句之后 |
| `Undefined variable: 'xxx'` | 拼写错误（类名/变量名不一致） |
| `syntax error, unexpected begin` | `foreach` 拼错 |
| `Illegal access to local/protected member` | 访问了不该访问的成员 |
| 编译通过但返回值是 0 | 有返回值的函数**漏写 `return`**（无警告！） |
| 运行时段错误 `signo [11]` | 空句柄上访问成员 |

详见 [[错题本 · 代码书写类]]。

## 三、按"想不通"查（结构理解类）

| 我以为是… | 其实是… |
| --- | --- |
| `super` 是个句柄 | `super` 是「**父类版本的方法**」，跟句柄无关 |
| `$cast` 会创建对象/转数据 | 只**加一个句柄 + 查类型**，不建对象不拷数据 |
| `t2 = t1` 会产生新对象 | 只是句柄复制，**同一个对象** |
| `fifo[$]` 需要实例化 | 队列**声明即创建**，直接可用 |
| `push_back` 存的是快照 | 存的是**句柄**，改对象后队列里的值跟着变 |
| 子类重写必须写 `virtual` | **关键在基类**，基类写了虚性就继承下来 |
| `virtual` 能让数据成员也多态 | `virtual` **只能修饰方法**，不能修饰数据成员 |
| 循环 4 次 new，内存就是 4 次的和 | `wd = new(i)` 是**句柄重指向**，只有最后一个存活 |

详见 [[错题本 · 结构理解类]]。

## 四、提交前自查清单（速查版）

**代码书写类（9 项）**

- [ ] 每个 `function`/`task` **头部行**末尾有 `;`？
- [ ] 每条赋值、调用末尾有 `;`？
- [ ] 形参名与成员同名时，成员侧写了 `this.`？
- [ ] `foreach` / 类名 / 变量名拼写一致？
- [ ] 声明是否都在语句**之前**？
- [ ] 有返回值的函数，**每条路径**都有 `return`？
- [ ] 动态数组 `[]` 是否 `new[n]` 了？（队列 `[$]` 不用）
- [ ] `$display` 的格式符个数 = 参数个数？
- [ ] 有返回值函数的调用，返回值用了吗？

**结构理解类（10 项自问）**

- [ ] 这行 `new()` 执行了几次？**当前几个对象存活**？
- [ ] `t2 = t1` 我复制的是对象还是句柄？
- [ ] `super.X()` 我读成"父类版本的方法"了吗？
- [ ] 我对 `$cast` 期待了多余的事吗？
- [ ] 子类构造函数调 `super.new()` 了吗？
- [ ] 这个函数在**改数据**还是**显示数据**？混了吗？
- [ ] 队列 `[$]` 是不是多此一举想给它 `new`？
- [ ] `push_back` 的语义我当"拷值"了吗？
- [ ] `virtual` 我检查的是**基类**还是子类？
- [ ] 题目问的是**当前占用**还是**累计分配**？

## 五、常用验证命令

概念拿不准时，直接跑一遍（本机已装 QuestaSim）：

```bash
vlog -sv 你的文件.sv
vsim -c -do "run -all; quit -f" 顶层模块名
```

> 提示：测试代码的 `$display` 建议用**纯英文**，避免终端中文乱码。
