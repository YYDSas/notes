## 一、按知识点速查

| 知识点 | 一句话 | 在哪儿 |
| --- | --- | --- |
| 类与对象的关系 | 类是设计图，对象是按图造的实例 | [[SV · 类与对象基础]] |
| 句柄 ≠ 对象 | 声明句柄不产生对象，`new()` 才产生 | [[SV · 类与对象基础]] |
| 数对象个数 | **`new()` 执行了几次，就有几个对象** | [[SV · 类与对象基础]] |
| 句柄赋值 | `t2 = t1` 只是复制句柄，不产生新对象 | [[SV · 类与对象基础]] |
| 参数传递与 `ref` | 默认按值传句柄副本，要"把新对象交出去"必须 `ref` | [[SV · 类与对象基础]] |
| `ref` 的额外要求 | 带 `ref` 的函数/任务必须是 `automatic` | [[SV · 类与对象基础]] |
| 动态数组 vs 队列 | 数组 `[]` 要 `new[n]`，队列 `[$]` 不用 | [[SV · 类与对象基础]] |
| `push_back` 存句柄 | 存的是门牌号，不是对象快照 | [[SV · 类与对象基础]] |
| 成员初始化顺序 | 声明初始化先执行，函数体赋值后覆盖 | [[SV · 类与对象基础]] |
| `local` / `protected` / public | 三级访问权限，外部一律不可越界 | [[SV · 封装 local-protected]] |
| 为什么需要封装 | 隐藏实现、便于维护、防误用 | [[SV · 封装 local-protected]] |
| `virtual` 分派 | 关键在**基类**，子类写不写都一样 | [[SV · 继承与 virtual 方法]] |
| `clone` 执行路径 | 子类 new 出新对象 → `super.clone` 拷父类字段 → 补子类字段 | [[SV · 继承与 virtual 方法]] |
| `super` 是什么 | 「父类版本的方法」，**不是句柄** | [[SV · 继承与 virtual 方法]] |
| 深拷贝 vs 浅拷贝 | `c.data = this.data` 只复制句柄，共享同一数组 | [[SV · 继承与 virtual 方法]] |
| `$cast` 的定位 | **换一个更"具体"的句柄 + 运行时类型检查** | [[SV · 类型转换与 $cast]] |
| `$cast` 使用顺序 | 先指向对象 → 再 cast → 最后调子类方法 | [[SV · 类型转换与 $cast]] |
| `$cast` 实测行为 | 失败**不改**目标句柄；源为 null 却返回成功 | [[SV · 类型转换与 $cast]] |
| 向上/向下转型 | 向上直接赋值，向下必须 `$cast` | [[SV · 类型转换与 $cast]] |
| `virtual` 不能修饰数据 | 数据成员不存在多态 | [[SV · 类型转换与 $cast]] |
| `$cast` 的两个主战场 | 换类句柄 + 给**枚举**做成员检查 | [[SV · 类型转换与 $cast]] |
| `enum → int` | **不需要 cast**，直接赋值；报错就是方向写反了 | [[SV · 类型转换与 $cast]] |
| `int → enum` | 必须 `$cast`，查的是**成员**不是区间 | [[SV · 类型转换与 $cast]] |
| 语句形式 vs 函数形式 | 越界时：语句**硬报错**，函数返回 0 | [[SV · 类型转换与 $cast]] |
| `$cast` 报错原文 | 「to type X from Y」= 目标 ← 源，**最容易读反** | [[SV · 类型转换与 $cast]] |
| 静态转换 `e_t'(5)` | **不检查**，直接给 5；要校验只能用 `$cast` | [[SV · 类型转换与 $cast]] |
| 选型口诀 | 转「位宽」用 `T'(...)`；校验「合法性」用 `$cast` | [[SV · 类型转换与 $cast]] |
| 打包 vs 非打包 | 维度写在**变量名左边**=打包，右边=非打包 | [[SV · 数据类型与位宽]] |
| `$bits` / `$size` | 总位数 vs **第一维**元素个数 | [[SV · 数据类型与位宽]] |
| 位宽不匹配 | 高位零扩展 / 静默截断，**两边都不报警告** | [[SV · 数据类型与位宽]] |
| 重复拼接 `{n{x}}` | 位宽 = 内层位宽 × n；内层必须定宽、n 必须常量 | [[SV · 数据类型与位宽]] |
| 动态数组 vs 队列 | 数组 `[]` 要 `new[n]`；队列 `[$]` 声明即创建 | [[SV · 数组与队列]] |
| 句柄数组 `new[5]` | 只分配 5 个**空槽**，不创建对象 | [[SV · 数组与队列]] |
| `new[8](ps)` | 扩容并复制旧元素；不带源参数则老元素全丢 | [[SV · 数组与队列]] |
| 动态数组拼接 | `buffer = {buffer, data}` 生成新数组再赋回 | [[SV · 数组与队列]] |
| `push_back` 存句柄 | 存的是门牌号，不是对象快照 | [[SV · 数组与队列]] |
| `new()` 不随机化 | 构造只初始化，`randomize()` 才随机 | [[SV · 随机约束]] |
| `soft` 约束 | 可被 inline 覆盖；UVM default constraint 就用它 | [[SV · 随机约束]] |
| `dist` 权重 | 是**期望比例**，有统计波动（4000 次实测） | [[SV · 随机约束]] |
| `inside {3,5}` vs `{[3:5]}` | 花括号=枚举集合，方括号=区间（★ 易错） | [[SV · 随机约束]] |
| `solve ... before` | **只能写变量名**，写表达式编译报错 | [[SV · 随机约束]] |
| rand 动态数组不约束 size | `randomize()` 返回 1 但 size=0，**静默失败** | [[SV · 随机约束]] |
| 随机失败后的变量值 | **保持原值不变**（需用哨兵值才能测出来） | [[SV · 随机约束]] |
| `constraint_mode()` | 只能当**语句**用；对象级开关会无差别全开 | [[SV · 随机约束]] |
| timescale | 编译 interface/module 必须显式写 | [[SV · 时钟与竞争]] |
| 竞争窗口 | posedge 驱动 + 同刻读取 → 谁先谁后不保证 | [[SV · 时钟与竞争]] |
| clocking block | `output/input #1ns` 从结构上消除竞争 | [[SV · 时钟与竞争]] |
| bin 划法 | bin 越细数字越低，**不可横向比较** | [[SV · 功能覆盖率]] |
| `auto_bin_max` | Questa 默认 64，8 位变量不会生成 256 个 bin | [[SV · 功能覆盖率]] |
| 覆盖率跑不出来 | **`$finish` 会终止 `-do` 脚本**（头号原因） | [[SV · 功能覆盖率]] |
| 没有 `xdisplay` | 只有 `$display/$write/$strobe/$monitor` | [[SV · 系统任务与打印]] |
| 裸百分号 `%` | 必须写 `%%`，否则 vopt 报错、设计加载失败 | [[SV · 系统任务与打印]] |
| 中文乱码 | 探针打印标签**必须纯 ASCII** | [[SV · 系统任务与打印]] |
| `$timeformat` / `%t` | 单位是 log10(秒)；小数只有 `$realtime` 有 | [[SV · 系统任务与打印]] |

## 三、学习方法提示

- **概念都靠"跑一遍"确认**：本机装了 QuestaSim，任何拿不准的行为都可以实测
  （见 [[错题本 · 索引]] 里的常用命令）
- **判断题先问"句柄还是对象"**：绝大多数 SV 陷阱都出在这个区分上
- **看代码先数 `new()`**：几处 `new` 就有几个对象
