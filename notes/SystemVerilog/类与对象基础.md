## 一、类与对象的关系

类是**设计图**（模板），对象是按图造出来的**具体实例**。同一个类可以造出多个对象，各自的属性值互相独立。

```systemverilog
class Pokemon {          // 类：模板
  string type;           // 属性（字段）
  function void move();  // 方法（行为）
  endfunction
endclass
```

| 概念 | 作用 |
| --- | --- |
| 类（class） | 抽象定义，说明"这一类东西有什么属性、能做什么" |
| 对象（object） | `new()` 造出的实体，占用实际内存 |
| 句柄（handle） | 指向对象的"门牌号"，本质是一个变量 |

**核心区分**：属性是名词（它是什么），方法是动词（它能做什么）。

## 二、句柄 ≠ 对象

这是 SV 最容易踩坑的地方。

```systemverilog
Transaction t;        // 只声明句柄，t == null，没有对象
t = new();            // 此刻才造出对象，t 指向它
```

- **声明句柄**：只是准备一个"门牌号变量"，什么对象都没产生
- **`new()`**：真正分配内存、创建对象

**调了几次 `new()`，就有几个对象**——这是判断对象个数最可靠的方法。

### 句柄赋值不产生新对象

```systemverilog
t1 = new();   // 对象①
t2 = t1;      // 句柄复制！t2 和 t1 指向【同一个对象】
```

`t2 = t1` 不调用构造函数，两个句柄值相同，改 `t2.addr` 就等于改 `t1.addr`。

## 三、参数传递：为什么必须用 ref

SV 的参数默认**按值传递**，传句柄时传的是**句柄的副本**。

```systemverilog
function void create(Transaction tr);   // ❌ 缺 ref
  tr = new();
  tr.addr = 100;
endfunction

Transaction t;
create(t);
t.addr = 10;        // 💥 t 仍是 null，空指针访问
```

执行过程：
1. 传参时 `tr` 拿到 `t` 的**副本**（此时都是 null）
2. `tr = new()` 让**局部变量 tr** 指向新对象，外部 `t` 不受影响
3. 函数返回后 `tr` 销毁，新对象失去引用，成为垃圾
4. 外部 `t` 从头到尾都是 null → `t.addr` 报错/崩溃

**正确写法**：

```systemverilog
function automatic void create(ref Transaction tr);   // ✅
  tr = new();
  tr.addr = 100;
endfunction
```

> **注意**：带 `ref` 参数的函数/任务**必须声明为 `automatic`**。否则编译报错：
> `(vlog-13300) The task or function ... with ref argument ... must be automatic.`

## 四、动态数组 vs 队列

| 类型 | 声明 | 要不要 new |
| --- | --- | --- |
| 动态数组 | `byte nb[];` | **要**：`nb = new[n];` |
| 队列 | `Transaction fifo[$];` | **不要**，天生可用 |

- **队列 `[$]`**：声明即创建，是"空但可用"的状态，可直接 `push_back` / `pop_front` / `size()`
- **动态数组 `[]`**：声明后未初始化，必须显式 `new[n]` 分配长度

### push_back 存的是句柄，不是对象

```systemverilog
t = new();                       // 全程只 new 一次
for (int i = 0; i < 3; i++) begin
  t.addr = i << 2;               // 反复改同一个对象
  fifo.push_back(t);             // 压入同一个句柄
end
// 结果：fifo[0]、fifo[1]、fifo[2] 全是 8（同一个对象的最新值）
```

要保存多个不同状态，必须每次 `new` 新对象：

```systemverilog
for (int i = 0; i < 3; i++) begin
  t = new();                     // new 挪进循环
  t.addr = i << 2;
  fifo.push_back(t);
end
```

## 五、调用 `wd = new(i)` 的字段赋值顺序

```systemverilog
class word;
  logic [31:0] addr = 'h10;      // ① 声明初始化先执行 → 16
  int a, b, d;
  byte data[8];
  function new(int a = 3, int d = 5);
    addr = a;                    // ② 函数体后执行 → 覆盖
    this.d = d;
    foreach (data[i]) data[i] = d;
  endfunction
endclass
```

`tr = new(10)` 的结果：
- `a` ← 10（外部传入，覆盖默认值 3）
- `d` ← 5（未传，用默认值）
- `addr` ← 10（`'h10` 的 16 被覆写）

> **易混淆**：`'h10` 是十六进制，值等于十进制 **16**；传入的 `10` 是十进制，值等于 10。
