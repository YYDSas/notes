> 调试全靠打印，而打印的几个格式细节最容易让人以为"仿真器坏了"。
> 本篇所有现象都在本机 QuestaSim 10.7c 复现过。

## 一、并没有 `xdisplay` 这个任务

```systemverilog
xdisplay("x", x);    // ❌ vopt-7063 Failed to find 'xdisplay'，设计无法加载
```

Verilog/SystemVerilog **只有** `$display / $write / $strobe / $monitor`（都要 `$` 开头）。
漏写 `$` 会得到"找不到任务"的加载错误。

## 二、$display 的格式符与裸百分号

```systemverilog
$display("x", x);            // 实测输出： x         42
$display("x = %0d", x);      // 推荐： x = 42
```

- **格式符个数必须与参数个数匹配**，否则报错：
  - 裸 `%` 无对应参数 → `vopt-2123 Missing argument for format specification`（**硬报错**）
  - 其它非法格式 → `(vopt-2122) Invalid format specification`，进而
    `vopt-2064 back-end code generation terminated with code 2` → `Error loading design`
  - **要打印百分号必须写 `%%`**，或干脆避开
- **参数多于格式符**时，Questa 会按**默认十进制补打**（不是忽略）——属实现行为，不可移植
- 字符串里**不能嵌套 ASCII 双引号**，会直接编译报错：

```
vlog-13067 unexpected non-printable character
```

## 三、⚠️ 中文一律乱码

Questa 控制台会把 `$display` 里的中文显示成 `??????` 或乱码（编码问题）。
**所有探针/演示脚本的打印标签必须是纯 ASCII**，否则返工。

> 这一条把探针脚本坑了不止一次。写 `[PHASE] start` 而不是 `[相位] 开始`。

## 四、$timeformat 与 `%t`

```systemverilog
$timeformat(unit_number, precision, suffix_string, min_field_width);
```

- `unit_number` = **log10(秒)**：`-12`=ps、`-9`=ns、`-6`=us、`-3`=ms、`0`=s
- 只影响 `%t` 的**显示**，不改仿真时间
- 同一时刻 2.234ns 的实测渲染：

| 调用 | 输出 |
| --- | --- |
| 默认（Questa 按 ps） | `2234` |
| `(-12, 2, "ps", 10)` | ` 2234.00ps`（宽度不足补空格） |
| `(-9, 3, "ns", 0)` | `2.234ns` |
| `(-6, 6, "us", 12)` | `  0.002234us` |

**三个要点**：

1. 小数部分只有 **`$realtime`** 才有：同一时刻 `$time` 打印 `2000.00ps`（整数 2ns 再换算），
   `$realtime` 打印 `2234.00ps`
2. `%0t` 里的宽度会**覆盖** `$timeformat` 的最小宽度
3. `$timeformat()` **无参调用**在 Questa 10.7c 下变成 `0ns`（不符合直觉，别依赖无参重置）

**`%t` 按 timescale 的精度渲染**：`1ns/1ps` 下 1ns 打印成 `@1000`（`$time` 的整数值其实仍是 1）。
想把日志里的 `@1000` 显示成 `@1ns`：tb 开头写

```systemverilog
$timeformat(-9, 0, "ns", 0);
```

或直接用 `%0d` 打印 `$time`，又或把 timescale 写成 `1ns/1ns`。

## 五、调试打印小抄

```systemverilog
$display("=== TEST1: cast fail ===");      // 纯 ASCII 标签
$display("  ret = %0d, ptr = %s", ret, (p==null) ? "NULL" : "non-null");
$display("  time = %0.3f ns", $realtime);  // 用 $realtime 拿小数
```
