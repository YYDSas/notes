## 拆句三步法

### 第一步：找主干

去掉所有修饰成分，只留 **主语 + 谓语 + 宾语**。

> The scientists **who had been working on the project for years** **announced** **that they had finally found a solution**.

主干：`The scientists announced that...`

### 第二步：切分修饰

- 从句：who / which / that 引导的定语从句
- 非谓语：doing / done / to do 作定语或状语
- 介词短语：in / of / with 引导的短语

### 第三步：还原语序

英文常把重要信息**前置或后置**，中文习惯**按时间顺序**。翻译时先理清逻辑再调整。

## 常见长难句结构

| 结构 | 特征 | 处理办法 |
| --- | --- | --- |
| 定语从句套定语从句 | 多个 who/which 连用 | 从最内层开始拆 |
| 插入语 | 两个逗号/破折号中间 | 先跳过，读完主干再回头 |
| 倒装 | 句首是否定词/only | 还原成陈述语序 |
| 省略 | 并列句中省掉重复成分 | 补全省略部分再理解 |

## 定位技巧

1. 题干中圈**关键词**（人名、数字、专有名词）
2. 回原文找**同义替换**，不要找原词
3. 答案句通常在关键词的**前后一句**内
4. 顺序原则：题目顺序与原文顺序基本一致
